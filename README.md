# C Learning Journey

## 1. About the project

This repository documents my learning journey in C through practical exercises. I'm a Computer Science student, and C is one of the main languages I'm currently studying.

This isn't a professional project or a production-ready library — it's a real record of my progress, including the trial and error along the way. Going through the exercises in order, you can actually see how I unlocked new concepts little by little.

## 2. Goals

- Learn the fundamentals of the C language;
- Develop programming logic;
- Learn to structure programs in a more organized way;
- Practice functions and data structures;
- Track my progress on GitHub;
- Eventually apply this knowledge to bigger projects.

## 3. Learning journey


## 4. Folder structure

```
01-Fundamentos/
02-Controle-de-Fluxo/
03-Loops-e-Padroes/
04-Funcoes/
05-Structs/
```

- **01-Fundamentos** — input/output, variables, types, and basic operators.
- **02-Controle-de-Fluxo** — decision-making with `if/else` and `switch`.
- **03-Loops-e-Padroes** — repetition with `while` and `for`, nested loops, and building visual patterns.
- **04-Funcoes** — function declaration, parameters, return values, and organizing logic into functions.
- **05-Structs** — arrays, strings, structs, and combining all of it in more complete exercises.

## 5. Exercises

### 01-Fundamentos
- Exercise 1 — basic input (name, age, height) with `scanf`/`printf`
- Exercise 3 — simple average between two grades

### 02-Controle-de-Fluxo
- Exercise 2 — calculator using `if/else`
- Exercise 4 — comparing two numbers
- Exercise 5 — grade classification (passed/borderline/failed)
- Exercise 6 — calculator using `switch`

### 03-Loops-e-Padroes
- Exercise 7 — simple `while` loop
- Exercise 8 — simple login/registration system
- Exercise 9 — `for` loop (simple counting)
- Exercise 10 — multiplication table
- Exercise 11 — counting even and odd numbers
- Exercise 12 — counting positives, negatives, and zeros
- Exercise 13 — rectangle of asterisks (nested loops)
- Exercise 14 — increasing triangle
- Exercise 15 — inverted triangle
- Exercise 16 — rectangle of `#`
- Exercise 17 — alternating row pattern
- Exercise 18 — checkerboard pattern (alternating using `(i + j) % 2`)

### 04-Funcoes
- Exercise 19 — first `void` function, no parameters
- Exercise 20 — function receiving a parameter (string)
- Exercise 21 — function with a return value (squaring)
- Exercise 22 — function with a return value (multiply by 2)
- Exercise 23 — function with two parameters (sum)
- Exercise 24 — function with internal conditional logic

### 05-Structs
- Exercises 26 to 32 — arrays, arrays of strings, a student registration struct, an array of structs, a function receiving a student, a function analyzing the student's status, and a function calculating the class average

> Note: the exact numbering of each exercise inside the `05-Structs` folder is still being sorted out on my end — the list above reflects the concepts already practiced, not necessarily a strict one-file-per-line mapping.
